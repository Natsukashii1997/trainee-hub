# 术语表（TraineeOS）

页面、PRD、issue、交接一律用左列的词。对象和命令以 [PRD](PRD.md) 上篇为准；本表只管叫法。v2.1（2026-11-14）起生效。

| 用这个词 | 指什么 | 数据上是 | 不要用 |
|---|---|---|---|
| TraineeOS | 本产品的显示名 | — | 管培生工作台（旧名，只在历史文档里出现） |
| 期次（批次标签） | 一批同时入职的管培生。v3.0 起降为可选的批次标签，成员按各自的入职日滚动入职（第二阶段执行） | `cohort` | 营地 |
| 路径模板 | 带版本号的标准培养方案（如 V2.4） | `path_template` / `stage` / `module` / `task_template` | 培养方案（只在说明内容来源时用） |
| 个人路径 | 某位管培生从模板派生的路径 | `personal_path` | 个人计划 |
| 阶段 | 路径里有明确目标的一组培养节点 | `stage` | — |
| 站 | 轮岗岗位；培养节点的分组 | `personal_module` | 模块（数据层旧名，界面不用） |
| 线 | 同一条路径里并行的几条主线（如业务线、技术线） | `task_instance` 的线字段 | 轨道 |
| 培养节点 | 路径上的一个学习、培训、实践或评审单元 | `task_instance` | 任务（单说「任务」容易和项目里的事混淆）；节点（单说「节点」容易和里程碑混淆） |
| 项目 | 有业务目标和责任人的持续性工作 | `project` | 项目实战（只作入口名） |
| 里程碑 | 项目里要交出关键成果或作出决定的检查点 | `milestone` | 关键节点、节点 |
| 成果版本 | 一次提交的飞书或 GitHub 链接，提交后不可改 | `submission` | 交付物、作品 |
| 评审 | 对一个成果版本（或培养节点的完成情况）下结论 | `review` | 批阅、验收（只在引用 TraineeOS 原文时用） |
| 评审方式 | 一个评审点用的规则：结论选项、是否打分与合格线、是否查否决项、是否要先交成果 | `review_method` | 评分标准 |
| 评审负责人 | 提交时快照下来的、负责评审这一版成果的带教 | `submission` 的快照字段 | 评审人（指实际评审的人时可用） |
| 认定 | 评审里程碑成果时，确认关联的培养节点达标 | `submission_credit` | — |
| 下一步行动 | 评审后谁要做什么 | `next_action` | 待办（待办是查询结果，不是对象） |
| 受阻 | 里程碑推进不下去、需要别人决定 | `blocker` | 阻塞 |
| 主带教 / 业务带教 / 项目带教 | 带教关系范围分别为全程 / 某一站 / 某个项目时的叫法 | `mentorship`（同一种对象） | 导师、业务导师 |
| 管理者 | 有管理权限的带教 | `user` 的管理权限字段 | 管理员（不是第三种角色） |
| 答疑记录 | 一条管培生提问及其答案、审核、归档、送达状态 | `qa_record` | FAQ（FAQ 只指 Q&A 合集） |
| Q&A 合集 | 答疑记录里归档为「已收录」的条目 | `qa_record` 的视图 | 知识库 |
| 亚古兽 | 常浩的企业分身（Hermes profile `agumon`），本产品的带教机器人 | `bot_client` 的接入方 | Hermes 带教、机器人（泛称时可用）、猛鬼兽（那是个人分身） |
| 牛马之家 | 常浩的个人工作台；带教模块正迁入本产品 | 外部系统 | 工作台（会和本产品混淆） |
| 任务标准 | 一个里程碑或培养节点开始前写清的五件事：为什么做、交付什么、怎样算好、常见失误、什么情况要及时找带教 | `milestone` 的目标、验收标准、常见失误、升级条件、样例链接 | SOP、课程 |
| 反馈条目 | 带教给某位管培生的一条反馈，来自评审或口头；可挂在成果、里程碑上 | `feedback_item` | 点评（泛称时可用）、批注 |
| 下次验证 | 带教标在一条反馈上，表示要在这个人之后的成果里看它有没有改 | `feedback_item` 的字段 | 跟进 |
| 验证 | 带教在后续成果上给一条反馈记结果：已改善、仍存在、这次没涉及 | `feedback_item` 的验证结果 | 复核 |
| 待我判断 | 带教首页：只列必须由带教判断的事（待评审、受阻待响应、待确认立项） | 查询，不是对象 | 判断队列、审批 |
| 可托付活动 | 一件可以明确交给人去做、做完能看出好坏的具体工作（第三阶段） | 待建 | 能力项（能力项是它的分组） |
| 独立性判断 | 某人在某项活动上是「证据不足、需指导完成、可独立完成」哪一种；「可指导他人」是另加的属性（第三阶段） | 待建 | 信任等级、能力评分 |
