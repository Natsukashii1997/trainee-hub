## Problem Statement
现有协作能记录与推进部分动作，但任务规则、关系语义和成果承载未对齐真实分工，专业生成与交付价值仍无同一真实样本的证据。

## Solution
围绕九月大学辅导开学营销，完成提案十项及必要兼容修改，让 AI 提供有来源的策略和完整文字、支持制作与审核交接推进，负责人查看全局与例外。本轮采用两页无价格《开学学习支持指南》及完整文字包，在真实 Base 中运行明确标注的 UAT 样本；模拟制作、审核与交接不能冒充真实业务完成。三角色通过群聊与卡片处理工作的正式能力目标保留，但本轮没有真实群发送授权。

十项的精确清单及各项最小范围以[营销战役优化提案 v1 第 3 节](</Users/nat/Documents/AI 项目/营销战役AI协同MVP/交付文档/营销战役优化提案_v1_20260906.md>)为准；本规格继承该清单，不扩增优化项。实施对照：Ticket 01 对应提案 02；Ticket 02 对应提案 03／04／05／06／09；Ticket 03 对应提案 07／08／10；Ticket 04 对应提案 01 及同一样本验收。

## User Stories
1. 业务负责人拿到查证过的目标、人群、SKU、策略与成果组合，承担商业定案。
2. 物料对接人直接拿到足够制作的需求，无需代 AI 补齐主体文案。
3. 审核人审核明确版本的终版，旧版本决定不能批准新版。
4. 已就绪成果可以制作，其他成果的缺口只阻塞相关内容。
5. 全部批准成果齐全、审核通过、可访问且交接完成后结束人工协作。
6. AI 自动汇总交付前过程，无二次签收、人工复盘和交付后私域跟踪。
7. 人读名称与稳定关系编号同时存在，主表名称变更自动同步。
8. 含价格权益的内容可回查具体年月、业务线、SKU 和条件。

## Implementation Decisions
- 本场采用 v2“开学先把学习难点看清楚”方向；Lite 作为已开课场景主介绍，选课指导限于适用的首次正式选课周期；完整无价格版不承载价格或促销承诺。
- 业务负责人、物料对接人、审核人均按用户决定绑定常浩。本轮为真实 Base UAT，不以单人模拟证明不同人员的真实业务协作。
- 模拟排期为 2026-09-07 定案版与制作需求绑定、09-08 至 09-09 制作及修订、09-10 集中终审与指定交接模拟；这些日期不是真实活动期限或人工耗时，UAT 可连续执行，无需等待日历。
- 模拟渠道采用朋友圈图文预览及配套私聊文字，入口沿用 v2 中性文本；接收方常浩。不得虚构真实发布账号、二维码、群号或外部链接，不触发真实群消息发送；模拟审核和交接须与正式业务事实区分。
- 保持五阶段、十一任务、五里程碑。任务正文采用提案第 02 项；MKT-008 的前置为 006；009 依赖 007 与 008，并对照 006 批准清单及版本查漏。发布新不可变 Release，不迁移历史战役。
- 初始化器以稳定字段 ID、类型和关联目标绑定；展示名称不作为内部业务键。保留用户手改列名，不恢复已删除版本状态列。
- 在战役补物料对接人与审核人，物料补直接战役编号及名称；既有 Link/lookup 只调整语义标签，沿用 ID。
- 用户目标与企业响应分名；只关联本场实际采用洞察。文字与设计保留各自输入和终版，可确定审核版本；保留既有附件。
- 批准清单不能由已经建好的物料记录反推。正式业务自动推进只认有权人的决定和回读证据，不把草稿、AI 判断或 UAT 模拟审核当人工批准；本轮 UAT 动作与结果明确标记。
- 先新增负责人工作视图，保护原视图手调布局。不预设新的企业底座、资产库或独立审批系统。

## Testing Decisions
测试位置是现有初始化网关和运行器的公开动作接口：验证新建战役能生成正确任务、缺项/旧版本不能错误完成、允许已就绪成果继续；这是技术实施选择，不改变已批准业务范围。优先复用现有 unittest 与隔离 FakeBase；行为改变先 red 后 green。真实 Base 中对明确标注的 UAT 结构、动作结果和原始字段统一回读；隔离测试和模拟审核/交接均不替代正式业务验收。

## Out of Scope
本场方向、无价格版及三角色常浩按用户已作决定记录；不代签其余业务决定，不把模拟终审或交接记成正式完成。本轮无真实群发送授权，不向群发消息或卡片；不虚构发布账号或承接入口。不迁移历史战役、不猜历史物料归属、不重做首列、不改权限与事件订阅。不安装 Skill、不修改 AGENTS.md、不启用 Hook/native runtime。不声称通用底座已完成。
