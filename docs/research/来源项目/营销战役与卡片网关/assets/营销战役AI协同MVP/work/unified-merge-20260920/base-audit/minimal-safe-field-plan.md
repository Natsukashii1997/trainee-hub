# 最小安全字段变更清单（供实施阶段使用）

本清单基于 2026-09-20 只读审计，只定义最小增量；不在审计阶段执行任何写入。原则是保留现有字段与数据，先加兼容字段、迁移并回读，验证后再决定是否隐藏或废弃旧字段。

## 1. 工作项目（`tbl1y77tCORXoZAr`）

### P0 必需

| 操作 | 字段 | 类型/选项 | 用途 |
|---|---|---|---|
| 新增 | 项目类型 | 单选：产品项目、营销战役 | 可靠选择模板并让日报/周报识别业务类型 |

| 新增 | 初始化状态 | 单选：待初始化、初始化中、已完成、失败 | 避免重复展开和未知状态重放 |
| 重命名 | `产品项目推进 副本-所属项目` → `营销战役推进` | 现有 Link 字段 `fld0JqtHC4` | 修复字段语义；不要删除重建 Link |

### 直接复用

- 战役名称 → `项目名称`（`fld2pPEYpg`）
- 负责人 → `总负责人`（`fldCjsprqU`）
- 开始时间 → 当前可映射`项目创建时间`（`fldpAalnAz`）；实施前确认是否允许把字段展示名改为“项目开始时间”，代码仍以 field_id 读取
- 项目任务 → `对应任务`（`fld7v0WFJ9`）

不新增独立的营销项目表。营销战役是`工作项目`中的一种项目，运行任务统一写入`任务事项`。

## 5. 任务事项与报告

- 日报/周报无需新增专用表；查询`状态=推进中`的工作项目及其关联任务即可，营销战役会自然成为其中一个项目板块。
- 先清理任务表中的 1 条全空任务并复核第二个项目的任务数/完成度，再把报告口径固定为：任务总数、已完成、逾期、近期截止、阻塞/待审核、最近交付物。
- `任务状态看板`当前按主责任人分组，应重命名为“负责人任务看板”或改成按完成/逾期状态分组。

## 6. 不应在第一批执行的变更

- 不删除现有 SKU Select、月份文本、项目模板关联字段或空记录，除非已完成迁移回读和影响检查。
- 不把 17 条营销模板记录直接关联某个真实项目作为运行态。
- 不恢复旧营销 Base 的入口或旧卡片回调。
- 不新增一套独立营销日报/周报，避免与统一项目汇报形成双口径。
