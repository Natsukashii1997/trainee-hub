## 一、施工结论

本轮采用“最小安全变更”原则：已验证的 AI 执行闭环、九表业务模型、状态版本、幂等字段、关系字段、5 个线上业务角色和 Dashboard 均保持原样。没有证据支持删表、并表、删字段、改字段类型、改状态选项或新增公式。

唯一实际施工项是将 6 条引用历史表/字段且当前停用的旧 Workflow 改名为 `归档｜…`，继续保持 `disabled`。这只改变后台资源名称，不改变触发图、不启用流程、不影响记录、权限或机器人闭环，便于后续区分“可用 V4 自动化”和“历史遗留定义”。

## 三、字段级动作矩阵

### 1. 统一动作规则

| 动作 | 本轮结论 |
|---|---|
| 保留 | 所有现有字段均保留；特别是状态版本、卡片消息 ID、附件指纹/签名、幂等键、来源消息 ID、环境字段和双向关系字段 |
| 合并 | 0 项。任务、物料、发布、资产、结果、AI 日志分别承担不同生命周期和权限边界，不建立万能表 |
| 改名 | 0 个业务表、0 个业务字段、0 个线上业务角色、0 个业务视图 |
| 删除 | 0 项。空值字段均经过运行时、角色、视图、关系、Dashboard、历史验收交叉检查 |
| 新增 | 0 项。没有确定性动作需要新增公式、Lookup、计算字段或新状态；不为“完整感”加字段 |
| 迁移 | 0 项。没有运行时字段或幂等字段改名需求；未来如需改名必须走兼容迁移协议 |

### 2. 低填充字段处置

| 字段类别 | 当前证据 | 处理 |
|---|---|---|
| 主卡片消息 ID（战役/任务/主题） | 当前未填或低填充，但属于历史卡片关联与兼容审计字段 | 保留；不复用、不改类型 |
| 当前风险 / 阻塞原因 / 待决策事项 | 只有在异常或待决策时填充，低填充符合语义 | 保留；作为失败路径与管理动作入口 |
| 来源依据 | 当前部分场景没有外部依据 | 保留；有来源时记录，不能因当前为空失去可追溯能力 |
| 交付链接 / 交付附件 / 参考附件 / 结果附件 | 业务链路允许无附件或通过卡片/外部链接交付 | 保留为可选证据字段，不强制填充，不新增自动化 |
| 物料关联月度折扣方案 | 当前 13 条物料均无关系边，但字段是预留跨场景关系，且权限配置仍引用 | 保留并继续隐藏在非必要角色视图中；后续真实流程证明无用后再评估 |
| 物料结果记录 | 反向关系在线存在，5 条结果覆盖 4 条物料、6 条边 | 保留；配置映射不补成运行时必需字段，避免把展示关系误变为运行时依赖 |
| AI 日志错误信息 | 成功运行不应产生错误文本，15% 填充对应失败/异常 | 保留；失败视图继续使用 |

## 四、视图与角色矩阵

9 张表共 36 个视图：每张表默认“表格”视图 + 27 个冻结业务视图。业务视图覆盖总览、待确认、执行中、待验收、风险、周度、甘特、提需、设计、审核、完成、投放日历、正式/UAT 隔离、复盘和 AI 失败排查等长期工作动作，暂无重复视图证据。

| 视图处理项 | 决定 | 原因 |
|---|---|---|
| `待提需确认` | 兼容保留，不删除、不改名、不移出角色导航 | 它已属于退役阶段，但审核人和提需人角色仍引用；直接删除会造成权限配置断链 |
| 默认“表格”视图 | 保留 | 是底层安全回退入口，不等于业务导航重复 |
| UAT/正式分视图 | 保留 | 是数据环境隔离证据，不能合并 |
| 角色可见业务视图 | 保留 | 5 个线上自定义角色的权限验收已通过 |

### 角色

保留并冻结 5 个线上业务角色：`战役管理者`、`内部执行者`、`设计协作者`、`审核人`、`提需人`。`Reader`、`Editor` 是 Base 内置角色，不作为业务角色重复项处理。角色字段权限、记录过滤、视图导航和 AI 日志不可见边界本轮不变。

## 五、公式、自动化、Workflow、Dashboard

### 公式与 Lookup

当前没有检测到公式字段，也没有明确的确定性计算缺口。本轮不新增公式/Lookup，避免把显示计算误当成业务事实源。

### Workflow

6 条 Workflow 全部为 `disabled`，且执行图引用当前不存在的历史表、字段和选项 ID，不能启用。处理方案为永久归档标识：仅改名为 `归档｜原名称`，继续保持停用。后续若重新启用，必须按当前 V4 字段与状态重建，先在 UAT 代表性记录验证，再单独审批启用；不在本轮重建或启用。

| 原 Workflow 类别 | 决定 |
|---|---|
| 任务 DDL 前 1 天提醒 | 归档标识，停用 |
| 任务逾期标记风险 | 归档标识，停用 |
| 物料下一动作 DDL 前 1 天提醒 | 归档标识，停用 |
| 物料下一动作逾期标记风险 | 归档标识，停用 |
| 口径到期自动失效 | 归档标识，停用；引用的旧“口径”表不属于当前九表 |
| 营销资产到期自动失效 | 归档标识，停用；引用的旧“资产”表不属于当前九表 |

### Dashboard

Dashboard `营销战役｜AI协同总控台 V4` 保留 10 个组件：系统说明、战役总数、未完成任务、未完成物料、战役阶段分布、任务状态分布、物料协同状态、物料健康分布、月度方案业务线、复盘记录类型。组件均以 `数据环境=UAT` 为主过滤条件；本轮不删、不改名、不重排、不改变数据源。
