## 怎么读

- 每份 `提取.md` 先看第 0 节（结论），再看「与工作台 PRD 的对照」一节（缺口和建议放在哪一块）。
- 文中的 `源/…` 指原项目根目录。原项目删除时先移到 `~/Archive/repos/待删/`，常浩真正删除之前还能找到原文。
- 标「已复制」的文件放在同目录的 `assets/` 下，相对路径和原项目相同。只有一处例外：原来的 `.scratch/` 被本仓库的 `.gitignore` 忽略，复制时改名为 `assets/_scratch/`。
- 拿不准的地方写在各自「待核」一节，没有经过核实，不要当成定论。
