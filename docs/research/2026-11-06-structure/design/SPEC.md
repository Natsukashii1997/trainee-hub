# 视觉方向预览：统一内容说明（三版共用）

项目：管培生工作台（公司内部，给管培生、带教人、管理员用）。产品负责人常浩觉得现有界面「不够高级、不够有质感」，要看三版明显不同的视觉方向。三版用同一套内容，只比较视觉。

参考现状：/Users/nat/Documents/ChatGPT/个人/work/trainee-hub/docs/design/home-01.html（现行视觉稿「01 器」，冷灰底、白面板、钴蓝强调；要在它之上明显升级，不是换个颜色）；示例数据 /Users/nat/Documents/ChatGPT/个人/work/trainee-hub/web/src/data/mock.ts。

## 硬性约束

- 每版两屏，各一个独立 HTML 文件，画布固定 **1440×900**（`html,body{width:1440px;height:900px;overflow:hidden;margin:0}`），内容不能溢出或被截断。只做电脑版。
- 文件完全自包含：CSS 内联；外部资源只允许 Google Fonts 的 stylesheet（`https://fonts.googleapis.com/css2?...`）；不引 JS 库；图标用内联 stroke SVG（统一线宽），不用 emoji、不用图片。
- 所有界面文字用简体中文。中文字体回落 `"PingFang SC","Noto Sans SC","Hiragino Sans GB",system-ui`；西文和数字可用 Google Fonts 的 Geist / Geist Mono / Inter 等（Google Fonts 的 CSS 自带 unicode-range，不会挡中文标点）。数字用 tabular-nums。
- 禁止：渐变铺底、左侧色条卡片、emoji、空洞的装饰插画、虚构的 lorem 文本。文字对比度 ≥ 4.5:1（小号灰字也要达标）。
- 写真实的 `<button>`、`<a>`、`<input>`；图标按钮带 `aria-label`；装饰 SVG `aria-hidden="true"`。

## 质量要求

目标是「一版交付」的品质：看起来像一线 SaaS 公司打磨过的产品，而不是模板。做到：
- 字号层级克制而清楚（建议不超过 6 级），间距基于 4/8 栅格，对齐严格。
- 层次靠精细的面（1px 内描边、极轻的多层阴影、面与面的明度差），而不是粗边框和重阴影。
- 每个组件都有细节：状态胶囊、进度环、轮岗站轨道、时间轴、迷你月历、头像，都要精致。
- 一屏只有一个视觉焦点；信息密度高但不挤。
- 气质参考（只学气质，不照抄任何产品的具体设计）：Linear、Vercel、Raycast、Notion Calendar、Things、Stripe Dashboard。
