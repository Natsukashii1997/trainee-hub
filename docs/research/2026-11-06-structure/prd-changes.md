## 第 4 节 成长

### 4-1 路径结构（4.1）：期次、站带教、截止推算、路径调整

- **原文**（L64–66）：
  - 三层：**阶段 → 模块（轮岗岗位）→ 任务**。阶段示例：入职、通识、轮岗、定岗。
  - **路径模板**由管理员维护，所有人可见；**个人路径**从模板派生，带上这个人的起止日期、轮岗顺序、每个模块的带教人。
  - 轮岗日历不单独维护，由所有人的个人路径汇总生成。
- **建议改为**：
  - 三层不变。**路径模板带版本号**，期次绑定一个模板版本。
  - **期次**（cohort）是独立对象：名称、模板版本、开学日、结束日、状态（筹备 → 进行中 → 已结束），个人路径挂在期次上。
  - 个人路径从模板派生，带上起止日期、轮岗顺序、**每站的站带教（带教关系的唯一来源）**和可选的**主带教**。同一人可以挂多站；入职、通识、定岗也各算一站，站带教可以是主带教或管理员。
  - 任务模板加「**截止规则**（锚点：站开始或站结束；偏移 N 个工作日；时刻）」和「建议用时（天）」；生成个人路径时按**工作日日历**落成具体日期，开放日 = 截止 − 建议用时。
  - **调整个人路径（顺延、换顺序、换站带教）是一个事件**：未开始的站和任务按新日期重排截止，已开始的站只能顺延，每次调整留痕（谁、原日期、新日期、原因）。
  - 轮岗排期（原「轮岗日历」）不单独维护，由所有人的个人路径汇总生成。
- **理由**：期次现在只是 `team` 的一个字段（L128），原型写死「2026 秋季班」（mock.ts:13）；模板只有建议用时、没有截止规则（Admin.tsx:118）；路径调整不重排任务（api.ts:106），和 issue #5 验收不一致。示例数据里 16 条路径任务有 7 条截止落在周末（coverage.md 5.4），国庆当天就是第一站开站日（mock.ts:68）。
- **依据**：PRD L64–66、L128、L130–131；原型 mock.ts:13、mock.ts:68-69、Admin.tsx:118、api.ts:106；走查 A-02、A-08、A-09、A-13、T-12（推演）；拍板 **B1**、**B5**、**B10**。

### 4-2 任务（4.2）：开放日、周期任务分型、需修改截止、改期、草稿、点评范围

- **原文**（L71）：两种类型：**路径任务**（属于某个模块）和**周期任务**（日报、周报、月度物料、轻测，贯穿整个培养期）。"我的进度"分两栏展示。
- **建议改为**：两种类型：**路径任务**（属于某个站）和**周期任务**（由**周期任务规则**展开生成）。周期任务按**完成方式**分四型：**提交链接**（日报，通道待定）、**机器人收周报**（周报只在机器人交，工作台只显示交没交，带教只看不评）、**机器人写成绩**（轻测：机器人出题，成绩写回；未作答记「未答」，不判逾期）、**本人声明 + 管理员确认**（月度物料）。周报、轻测成绩作为对应周期任务实例的完成凭证。"我的进度"分两栏展示。
- **理由**：这一条同时修订 issue #6 的验收「周期任务与路径任务共用状态流转和提交方式」。原型把轻测做成交「文档」的普通任务（mock.ts:114，还写成「带教人出题」，与 L78 矛盾），周报出现「已通过」状态（mock.ts:117），和机器人写周报、写成绩的接口（L155）对不上；周期任务如果都要站带教评，工作量翻倍，带教是兼职（推演）。
- **依据**：PRD L71、L78、L112、L155；原型 mock.ts:114-117、api.ts:176-182；旁证：机器人业务共识 v1.0 第 99 行「每周一次，每次 2—3 道」、第 107 行「没有作答只记为'未答'」、第 111–126 行月度物料走「提醒、本人声明、导师确认」（推演，待常浩确认）；走查 T-07、T-08、M-08；拍板 **B4**。

- **原文**（L73）：状态流转：未开始 → 进行中 → 已提交 → 需修改 / 已通过；超过截止时间自动标"逾期"。
- **建议改为**：状态流转：未开始 →（**到开放日自动**，或本人点开始）进行中 → 已提交 → 需修改 / 已通过。**点评为「需改进」时同时给修改截止**（默认 N 个工作日，N 由常浩定）。超过截止（需修改时看修改截止）自动标"逾期"。**截止可由本站带教或管理员调整，必须写原因，留痕**。不支持草稿：飞书文档本身就是活文档，提交即正式提交。
- **理由**：PRD 没写「未开始 → 进行中」的触发，原型里这个状态是示例数据写死的（mock.ts:112）；打回后原截止早过，任务一律显示逾期，带教的「需要跟进」会被淹没，主指标也被污染；示例数据里有草稿提交（mock.ts:147、154），但接口一交就置为已提交（api.ts:161-162），算法分不出来。
- **依据**：PRD L73、L178；原型 mock.ts:112、mock.ts:147、mock.ts:154、api.ts:157-163；走查 T-14、T-18、M-15、A-08（推演）；拍板 **B5**。
